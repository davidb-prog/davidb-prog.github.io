Données personnelles

Le Petit labo ne demande aucun compte, ne dépose aucun cookie, n’affiche aucune publicité.

Il compte les visites avec GoatCounter, un outil de mesure d’audience sans cookie : il note la page vue, le site d’où l’on vient, le pays et le type d’appareil, sans stocker l’adresse IP ni identifier la personne.

Aucune donnée n’est vendue ni transmise à des fins publicitaires. Pour toute question : bonjour@petit-labo.fr

Retour au Petit labo
